現在のノートの `ローカルグラフ` を、ノート本文のすぐ下に表示します。
ノート下部の空きスペースを活用しましょう！

![サンプル画像](./res/example-word.png)

## なぜ必要か

Obsidian 標準のローカルグラフはサイドパネルにあります。開いて、幅を調整して、
読んでいる場所から視線を外す必要があります。Inline Local Graph は同じ情報を、
すでに目が向いている場所 — ノートの末尾、いつもは空白のスペース — に置きます。

短いのにリンクが密なノート、つまり単語カード・用語集・デイリーノート・MOC のように
**リンクそのものが中身である**ノートで特に役立ちます。

### 例: 外国語の単語学習

上のスクリーンショットは日本語の単語 言語（*げんご*）の単語カードです。
読み（げんご）、韓国語・英語の対応語（언어 / language）、この語を構成する漢字（言、語）、
そしてよく一緒に使われる動詞（学ぶ）へリンクが伸びています。

単語ひとつの「家族」がカードのすぐ下に並ぶので、ひとつの語を復習すると周辺の語も
自然と目に入ります。サイドパネルも、文脈の切り替えも不要です。

## 機能

### 実用重視のローカルグラフ表示

派手な視覚効果ではなく分かりやすさに重点を置いたローカルグラフで、発リンクと被リンクを表示し、
ノート間の関係の把握と移動を容易にします。

- **発リンク / 被リンク** — コントロールバーまたは設定から個別に切り替えられます
- **ノードスタイル** — 形状、背景色、フォントサイズ
- **ラベルの省略** — アルファベットと CJK（韓国語・日本語・中国語）で別々の文字数制限を適用し、
  全角文字でノードが間延びしません
- **表示ノード数の上限** — リンクの多いノートでもグラフが過密になりません
- **画像リンクを除外** — 埋め込み画像がグラフを乱しません
- **多言語 UI** — 英語、韓国語、日本語

## インストール

### コミュニティプラグインから

1. **設定 → コミュニティプラグイン**を開き、制限モードをオフにします。
2. **参照**をクリックし、**Inline Local Graph** を検索します。
3. **インストール**して**有効化**します。

### 手動インストール

1. [最新リリース](https://github.com/TKOxff/obsidian-inline-local-graph/releases)から
   `main.js`、`manifest.json`、`styles.css` をダウンロードします。
2. `<保管庫>/.obsidian/plugins/inline-local-graph/` にコピーします。
3. Obsidian を再読み込みし、**設定 → コミュニティプラグイン**で有効化します。

## 使い方

プラグインを有効にするだけで、ノート下部にインラインローカルグラフが自動的に表示されます。

グラフの上には小さなコントロールバーがあります。

| コントロール | 動作 |
| --- | --- |
| **発リンク** | 現在のノートから出るリンクの表示 / 非表示 |
| **被リンク** | 現在のノートを指すバックリンクの表示 / 非表示 |
| **+ / −** | グラフの拡大・縮小 |

ノードをクリックするとそのノートが開きます。マウスホイールでのズームは意図的に無効化されており、
ノートをスクロール中にグラフ内で止まってしまうことがありません。

## 設定

**設定 → コミュニティプラグイン → Inline Local Graph** から変更できます。

### グラフ

| 設定 | 説明 | 既定値 |
| --- | --- | --- |
| 辺に矢印を表示 | グラフの辺に矢印を表示します。 | オン |
| グラフの枠線を表示 | グラフコンテナの枠線の表示を切り替えます。 | オフ |
| 発リンクを表示 | グラフに発リンク（アウトゴーイング）を表示するかを切り替えます。 | オン |
| 被リンクを表示 | グラフに被リンク（バックリンク）を表示するかを切り替えます。 | オン |
| 画像リンクを除外 | グラフから画像ファイルを除外するかを切り替えます。 | オン |
| 初期ズーム | インライングラフの初期ズーム倍率を設定します。 | 1.0 |
| 最大表示ノード数 | グラフに表示するノードの最大数（常に表示される現在のノートは除く）。被リンクより発リンクが優先されます。範囲 1〜200。 | 30 |

### ノードスタイル

| 設定 | 説明 | 既定値 |
| --- | --- | --- |
| ノードの形状 | 楕円、四角、円、ドット、テキストのみ から選択します。 | 四角 |
| ノードの背景色 | グラフノードの背景色を設定します。 | `#888888` |
| ノードのフォントサイズ | ノードラベルのフォントサイズを設定します。 | 14 |
| ラベルを省略 | 長いノードラベルを省略記号（...）で短縮します。 | オン |
| 最大ラベル長（アルファベット言語） | アルファベット言語のラベルを省略するまでの最大文字数。 | 20 |
| 最大ラベル長（韓国語/日本語/中国語） | 非アルファベット言語のラベルを省略するまでの最大文字数。 | 10 |

## 依存関係

このプラグインは [vis-network.js](https://visjs.github.io/vis-network/) ライブラリを使用して、
ノート内にインタラクティブなネットワークグラフを描画します。
