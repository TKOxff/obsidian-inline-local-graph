## 왜 필요한가

옵시디언의 기본 로컬 그래프는 사이드 패널에 있습니다. 열고, 크기를 조절하고, 읽던 곳에서
시선을 옮겨야 하죠. Inline Local Graph는 같은 정보를 이미 눈이 가 있는 곳 —
노트 끝의 비어 있던 공간 — 에 놓아줍니다.

짧지만 링크가 촘촘한 노트, 즉 단어 카드·용어집·데일리 노트·MOC처럼 **링크 자체가 내용인**
노트에서 특히 유용합니다.

### 예시: 외국어 단어 학습

위 스크린샷은 일본어 단어 言語(*겐고*, "언어")의 단어 카드입니다.
읽는 법(げんご), 한국어·영어 표기(언어 / language), 이 단어를 이루는 한자(言, 語),
그리고 자주 함께 쓰이는 동사(学ぶ)로 링크가 뻗어 있습니다.

단어 하나의 "가족"이 카드 바로 아래에 놓이므로, 한 단어를 복습하면 이웃 단어들이 함께
눈에 들어옵니다. 사이드 패널도, 문맥 전환도 없습니다.

## 기능

### 실용적인 로컬 그래프 시각화

화려한 시각 효과 대신 명료함에 집중한 로컬 그래프로, 링크와 백링크를 표시해
노트 사이의 관계를 파악하고 이동하기 쉽게 합니다.

- **나가는 링크 / 들어오는 링크** — 컨트롤 바나 설정에서 각각 독립적으로 켜고 끌 수 있습니다
- **노드 스타일** — 모양, 배경색, 글꼴 크기
- **라벨 줄임** — 알파벳과 한글/일본어/중국어에 각각 다른 길이 제한을 적용해,
  전각 문자 때문에 노드가 길어지지 않습니다
- **표시 노드 수 제한** — 링크가 많은 노트에서도 그래프가 과밀해지지 않습니다
- **이미지 링크 제외** — 첨부 이미지가 그래프를 어지럽히지 않습니다
- **다국어 UI** — 영어, 한국어, 일본어

## 설치

### 커뮤니티 플러그인으로 설치

1. **설정 → 커뮤니티 플러그인**을 열고 제한 모드를 해제합니다.
2. **탐색**을 눌러 **Inline Local Graph**를 검색합니다.
3. **설치** 후 **활성화**합니다.

### 수동 설치

1. [최신 릴리즈](https://github.com/TKOxff/obsidian-inline-local-graph/releases)에서
   `main.js`, `manifest.json`, `styles.css`를 내려받습니다.
2. `<보관소>/.obsidian/plugins/inline-local-graph/` 안에 복사합니다.
3. 옵시디언을 다시 불러온 뒤 **설정 → 커뮤니티 플러그인**에서 활성화합니다.

## 사용법

플러그인을 활성화하기만 하면 노트 하단에 인라인 로컬 그래프가 자동으로 나타납니다.

그래프 위에는 작은 컨트롤 바가 있습니다.

| 컨트롤 | 기능 |
| --- | --- |
| **나가는 링크** | 현재 노트에서 나가는 링크를 표시하거나 숨깁니다 |
| **들어오는 링크** | 현재 노트를 가리키는 백링크를 표시하거나 숨깁니다 |
| **+ / −** | 그래프를 확대·축소합니다 |

노드를 클릭하면 해당 노트가 열립니다. 마우스 휠 확대/축소는 의도적으로 비활성화되어 있어,
노트를 스크롤하다 그래프 안에 갇히는 일이 없습니다.

## 설정

**설정 → 커뮤니티 플러그인 → Inline Local Graph**에서 조정할 수 있습니다.

### 그래프

| 설정 | 설명 | 기본값 |
| --- | --- | --- |
| 엣지에 화살표 표시 | 그래프 엣지에 화살표를 표시합니다. | 켬 |
| 그래프 테두리 표시 | 그래프 컨테이너의 테두리 표시를 전환합니다. | 끔 |
| 나가는 링크 표시 | 그래프에 나가는 링크를 표시할지 전환합니다. | 켬 |
| 들어오는 링크 표시 | 그래프에 백링크(들어오는 링크)를 표시할지 전환합니다. | 켬 |
| 이미지 링크 제외 | 그래프에서 이미지 파일을 제외할지 전환합니다. | 켬 |
| 초기 확대/축소 | 인라인 그래프의 초기 확대/축소 배율을 설정합니다. | 1.0 |
| 최대 표시 노드 수 | 그래프에 표시할 노드의 최대 개수(항상 표시되는 현재 노트는 제외). 백링크보다 나가는 링크가 우선 표시됩니다. 범위 1~200. | 30 |

### 노드 스타일

| 설정 | 설명 | 기본값 |
| --- | --- | --- |
| 노드 모양 | 타원, 박스, 원, 점, 텍스트만 중에서 선택합니다. | 타원 |
| 노드 배경색 | 그래프 노드의 배경색을 설정합니다. | `#888888` |
| 노드 글꼴 크기 | 노드 라벨의 글꼴 크기를 설정합니다. | 14 |
| 라벨 줄임 | 긴 노드 라벨을 말줄임표(...)로 줄입니다. | 켬 |
| 최대 라벨 길이 (알파벳 언어) | 알파벳 언어의 라벨을 줄이기 전 최대 글자 수. | 20 |
| 최대 라벨 길이 (한글/일본어/중국어) | 비알파벳 언어의 라벨을 줄이기 전 최대 글자 수. | 10 |

## 의존성

이 플러그인은 [vis-network.js](https://visjs.github.io/vis-network/) 라이브러리를 사용해
노트 안에 인터랙티브한 네트워크 그래프를 렌더링합니다.
