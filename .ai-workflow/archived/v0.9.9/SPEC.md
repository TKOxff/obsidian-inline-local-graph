## 1. 목표 (Why)

- 노드의 텍스트가 길어질 때 표시 영역에 맞춰 줄이는(truncation) 처리가 현재 영어와 비영어(한국어/일본어/중국어 등)를 동일한 기준으로 다뤄, 언어별로 잘림 위치·길이가 부자연스럽게 보이는 문제가 있다.
- 영어(라틴 문자)와 그 외 언어는 글자당 폭과 단어 경계 특성이 다르므로, **텍스트 줄임 로직을 영어와 그 외 언어로 분리**하여 각 언어에 맞는 자연스러운 줄임 결과를 제공한다.

## 2. 작업 범위 (Scope)

- 노드 텍스트 줄임 처리에서 영어(라틴)와 그 외 언어를 판별하는 기준 정의
- 영어/비영어의 최대 글자 수(max length)를 각각 별도 설정값으로 분리
- 줄임은 단순 절단(단어 경계 처리 없음)으로 처리하고 말줄임(`...`) 부착
- 혼합 텍스트(영어 + 비영어 혼재)는 CJK 포함 시 비영어 기준 적용
- (추가) 설정/UI 메시지 다국어(i18n) 지원 — 한국어·일본어 우선, 영어 fallback

## 3. 요구사항 / 수용 기준 (Acceptance Criteria)

- 영어 문자열이 표시 폭을 넘으면 영어 기준 로직으로 줄여지고 `…`가 부착된다.
- 비영어(예: 한국어/일본어/중국어) 문자열이 표시 폭을 넘으면 해당 언어 기준 로직으로 줄여진다.
- 영어와 비영어가 혼합된 문자열도 깨지지 않고 일관된 기준으로 줄여진다.
- 줄임이 필요 없는(짧은) 텍스트는 그대로 표시된다.
- 기존 노드 표시 동작에 회귀(regression)가 없다.

## 4. 영향 범위 / 고려사항

- 영향 대상: 노드 텍스트 렌더링/줄임 처리 모듈 (구현 위치는 `PLAN.md`에서 코드 분석 후 확정).
- 언어 판별 기준(유니코드 범위/정규식)의 정확도와 성능.
- 혼합 텍스트의 경계 판정 시 엣지 케이스(이모지, 숫자, 기호 등).
