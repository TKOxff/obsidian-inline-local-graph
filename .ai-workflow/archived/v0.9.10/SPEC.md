## 1. 목표 (Why)

- 링크/백링크가 매우 많은 노트에서 인라인 그래프가 과도하게 많은 노드로 과밀해져 가독성이 떨어진다.
- 그래프에 표시되는 노드 개수의 **최대치를 사용자가 설정**할 수 있게 하여, 과밀을 방지하고 핵심 연결만 보이도록 한다.

## 2. 작업 범위 (Scope)

- 표시 노드 최대 개수 설정 `maxNodes` 신설 (기본값 30)
- 노드 생성 시 상한 적용 — 활성 노트 노드는 항상 포함, 나머지를 상한까지만 표시
- 상한으로 잘려나간 노드를 참조하는 엣지 제거 (dangling edge 방지)
- 설정 탭에 'Max displayed nodes' 슬라이더 추가
- 위 설정/UI 문자열 i18n(en/ko/ja) 반영

## 3. 요구사항 / 수용 기준 (Acceptance Criteria)

- 노드 총수가 `maxNodes`를 초과하면 상한 개수까지만 표시된다.
- 활성 노트 노드는 상한과 무관하게 항상 표시된다.
- 잘려나간 노드를 가리키는 엣지가 남지 않는다.
- 설정 슬라이더에서 값을 바꾸면 그래프가 즉시 갱신된다.
- 기존 설정이 없는 사용자도 기본값(30)으로 정상 동작한다(하위 호환).

## 4. 영향 범위 / 고려사항

- 변경 대상(초안): `src/main.ts`(설정), `src/InlineGraphView.ts`(노드/엣지 생성), `src/InlineGraphSettingTab.ts`(UI), `src/i18n.ts`(문자열).
- 상한 도달 시 **어떤 노드를 우선 남길지**(아웃고잉 우선 vs 백링크 우선, 정렬 기준)는 PLAN에서 확정 필요.
- 슬라이더 범위(최소/최대값) 확정 필요.
